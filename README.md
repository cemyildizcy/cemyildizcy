## Selected work

- [Bike Demand: Temporal ML](https://github.com/cemyildizcy/bike-demand-temporal-ml) — a chronological benchmark on the [UCI Bike Sharing dataset](https://doi.org/10.24432/C5W894). The selected calendar-plus-observed-weather ridge model reports final-test MAE 77.79 bikes versus 103.54 for a seasonal-naive baseline. One city, two years; observed weather is not an advance forecast.
- [Fashion-MNIST: NumPy MLP Study](https://github.com/cemyildizcy/fashion-mnist-numpy-capacity) — compared a NumPy softmax baseline with a two-hidden-layer ReLU MLP at 10% and 100% training data, including two synthetic noise conditions. At 100%, the MLP scored 3.47 percentage points higher in clean test accuracy in one seed/split; AI-assisted, descriptive results only.
- [GündemAI](https://play.google.com/store/apps/details?id=com.gundemai.app) — an Android news app available on Google Play.
- [WC2026 AI Simulator](https://github.com/cemyildizcy/wc2026-ai-simulator) — an educational tournament simulator using Poisson distributions and Monte Carlo. It is not a trained machine-learning model.
